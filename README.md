# Hand Solitaire

## Summary

A simple game in which a small set of cards is displayed and a very few
rules are utilized on a standard deck of playing cards with the goal being to discard
all cards which signifies winning the game.  Badges are awarded for both winning the 
game and for coming close at different levels.  There is a path to exchanging lower value
badges for higher level ones to move up display levels in the game. Overall, this is a
relaxing game that utilizes art to motivate the player to move up in level.
